## Testing

There is no application code or automated test suite in this repository yet. Once tests are added, document the test command here and run it before pushing changes.

## Push changes

From the repository directory, review and commit your changes, then push the `main` branch to GitHub:

```sh
git status
git add <files>
git commit -m "Describe your changes"
git push origin main
```

Replace `<files>` with the paths you changed, or use `git add -A` to stage all changes after reviewing `git status`.
